Dark Mode Website Hub

Your sites, one home.

This hub gives you one dark-mode homepage where you can jump into your main website, keep a list of other links, and preview the selected site without leaving the page.

Featured website Highlight your main site and open it instantly.
Live preview See the selected website inside the hub when embedding is allowed.
Easy template Add more sites by copying one small object in the list.
How it works

Click any site card on the right and the big preview area updates. The action buttons let you open the real website, while the template below shows exactly how to add more links.

Best use

Use your own URL for the first card, then stack social pages, portfolios, stores, docs, or anything else.

Add More Sites

Open the script at the bottom of this file and add another object inside the sites array using this template. 

{
  title: "New Website",
  description: "Short line about what the site is for.",
  url: "https://your-link.com",
  preview: "https://your-link.com",
  category: "Portfolio",
  status: "Live now",
  use: "Sharing work",
  label: "Preview"
}
Tip: if a website does not preview inside the iframe, keep the same url and just use the hub as a launcher.
